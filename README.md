## English

An open-world 2D Top-Down Cultivation RPG built from scratch using **Java 25** and **JavaFX**.

### 🚀 Quick Start
1. **Play the game:** Download the latest release from the [Releases](https://github.com/Safik121/DaoEngine/releases) section, unzip, and run `DaoEngine.exe`.
2. **Build from source:**
   ```bash
   mvn clean package
   mvn javafx:run
   ```

### 📖 Documentation
- [English Game Manual](USER_DOCUMENTATION_EN.md)
- [Technical Documentation (Architecture)](TECHNICAL_DOCUMENTATION_EN.md)

### ✨ Key Features
- **Data-Driven Design:** All game entities, items, and quests are loaded from JSON.
- **Procedural Generation:** Unique biomes (Forest, Ice, Fire) generated for every Realm.
- **Event-Driven Core:** Decoupled systems using a Mediator pattern.
- **Heavenly Tribulations:** Survive the wrath of the heavens during breakthroughs.

## Čeština

2D Top-Down RPG s otevřeným světem a prvky kultivace, vytvořené od úplného základu v **Javě 25** a **JavaFX**.

### 🚀 Rychlý start
1. **Zahrát si:** Stáhni si nejnovější verzi v sekci [Releases](https://github.com/Safik121/DaoEngine/releases), rozbal ZIP a spusť `DaoEngine.exe`.
2. **Sestavit ze zdrojáků:**
   ```bash
   mvn clean package
   mvn javafx:run
   ```

### 📖 Dokumentace
- [Český herní manuál](USER_DOCUMENTATION.md)
- [Technická dokumentace (Architektura)](TECHNICAL_DOCUMENTATION.md)

### ✨ Klíčové funkce
- **Data-Driven Design:** Entity, předměty i úkoly jsou definovány v JSON souborech.
- **Procedurální generování:** Unikátní biomy (Les, Led, Oheň) pro každou říši.
- **Event-Driven Jádro:** Nezávislé systémy propojené přes Mediator pattern.
- **Nebeské Tribulace:** Přežij hněv nebes při průlomu na vyšší úroveň kultivace.
