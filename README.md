# 仙 DaoEngine: Path to Immortality

An open-world 2D Top-Down Cultivation RPG built from scratch using **Java 25** and **JavaFX**. 

Experience the journey from a mortal to a celestial being in a dynamically generated world filled with Heavenly Tribulations, ancient sects, and legendary artifacts.

## 🚀 Quick Start
1. **Play the game:** Download the latest release from the [Releases](https://github.com/Safik121/DaoEngine/releases) section, unzip, and run `DaoEngine.exe`.
2. **Build from source:**
   ```bash
   mvn clean package
   mvn javafx:run
   ```

## ✨ Key Features
- **Data-Driven Design:** All game entities, items, and quests are loaded from JSON.
- **Procedural Generation:** Unique biomes (Forest, Ice, Fire) generated for every Realm.
- **Event-Driven Core:** Decoupled systems using a Mediator pattern for maximum scalability.
- **Advanced Combat:** Skill-based combat system with status effects and projectiles.
- **Heavenly Tribulations:** Survive the wrath of the heavens as you breakthrough to higher realms.
